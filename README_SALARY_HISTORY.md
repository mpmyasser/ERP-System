# 📖 نظام السجل التاريخي للرواتب - دليل البدء
# Salary History System - Getting Started Guide

**🎉 مرحباً بك في نظام السجل التاريخي للرواتب**

---

## 🚀 البدء السريع (5 دقائق)

### خطوة 1: ادخل إلى النظام
```
من القائمة الرئيسية → التقارير → السجل التاريخي للرواتب
```

### خطوة 2: اختر المرشحات
```
- الموظف: (اختياري)
- من التاريخ: (اختياري)
- إلى التاريخ: (اختياري)
```

### خطوة 3: اعرض التقرير
```
انقر "بحث" لعرض النتائج
```

### خطوة 4: صدر التقرير
```
انقر "تصدير Excel" للحصول على ملف
```

## 🎯 الحالات الاستخدام الشائعة

### حالة 1: تتبع تعديلات موظف
```
1. ادخل التقرير الشامل
2. اختر اسم الموظف
3. انقر بحث
4. اعرض جميع التعديلات
```

### حالة 2: تقرير شهري
```
1. حدد من تاريخ: 01/12/2025
2. حدد إلى تاريخ: 31/12/2025
3. اترك الموظف فارغاً (لجميع الموظفين)
4. صدّر إلى Excel
```

### حالة 3: معلومات موظف فردي
```
1. من التقرير الشامل: انقر على رقم الموظف
2. شاهد الرسم البياني
3. اعرض جميع التعديلات
4. ادرس الإحصائيات
```

## 📊 ماذا يعرض التقرير؟

### الإحصائيات:
- 📊 عدد مرات التعديل
- 💰 إجمالي الزيادات المالية
- 📉 إجمالي التخفيضات
- 🔄 الفرق الإجمالي

### تفاصيل كل تعديل:
- تاريخ ووقت التعديل
- الراتب القديم والجديد
- مبلغ التغيير
- نوع التغيير (زيادة/تخفيض)
- السبب والملاحظات
- من قام بالتعديل

### الرسوم البيانية:
- تطور الراتب عبر الزمن
- معدل التغيير
- المقارنات

### نصيحة 2: استخدم المرشحات
```
استخدم المرشحات للحصول على:
- التقارير المحددة
- البيانات الدقيقة
- المقارنات الصحيحة
```

### نصيحة 3: راجع الرسم البياني
```
الرسم البياني يوضح:
- الاتجاهات
- التطور الزمني
- الأنماط
```

### نصيحة 4: استخدم التصدير
```
صدّر للحصول على:
- ملفات قابلة للتشارك
- بيانات للتحليل
- نسخ للأرشفة
```

## ❓ الأسئلة الشائعة

### س: متى يتم تسجيل التعديلات?
**ج:** عند كل تعديل على راتب الموظف في النظام

### س: هل يمكن حذف السجلات?
**ج:** لا، السجلات دائمة للأمان والتدقيق

### س: ما هي دقة الوقت?
**ج:** دقيقة كاملة (ساعة:دقيقة:ثانية)

### س: هل يشمل التقرير جميع الموظفين?
**ج:** نعم، إذا لم تختر موظفاً محدداً

### س: هل الملفات المصدرة آمنة?
**ج:** نعم، تتضمن جميع البيانات بأمان
